## Sleep Efficiency Analysis (EDA)

This project performs Exploratory Data Analysis (EDA) on sleep efficiency data using Python and Jupyter Notebook.  
It explores relationships between sleep efficiency and factors such as age and sleep duration through visualizations and summary statistics.

### Project Files
- sleep_efficiency.ipynb – main notebook containing EDA and plots
- Sleep_efficiiency.csv - for dataset

### Libraries Used
- Python  
- pandas  
- matplotlib 
- seaborn 

### Purpose
This project was created to practice Exploratory Data Analysis and data visualization techniques.
